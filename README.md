# 哨兵机器人视频监控

本地网页监控原型：上传视频后逐帧检测动物、烟雾和火焰；检测框直接叠加在视频画面上，连续出现超过 1 秒时网页显示告警并播放提示音。

## 启动

Windows 用户也可以直接双击项目目录中的 `启动哨兵监控.bat`。脚本会检查 Python、安装依赖并打开网页；首次运行安装依赖时需要联网。

在项目目录的 PowerShell 中运行：

```powershell
python -m pip install -r requirements.txt
python app.py
```

浏览器打开 `http://127.0.0.1:5000`，选择视频并点击“开始检测”。首次运行会加载模型，较大的模型需要等待一会儿。

## 模型配置

默认动物模型为仓库中的 `yolov8n.pt`（COCO 类别，包含猫、狗及常见动物），火烟模型为 `yolo11-d-fire-dataset.pt`。启动前可以设置环境变量 `ANIMAL_MODEL`、`FIRE_MODEL` 更换权重；`DETECTION_CONFIDENCE` 可调整置信度阈值（默认 0.25）。动物模型类别名称应包含猫、狗或其他动物类别，火烟模型类别名称应包含 fire、flame 或 smoke。

告警时序按同一风险类型聚合；连续帧间隔不超过 0.6 秒视作持续出现。当前版本面向本机单路视频演示，尚未实现多路摄像头管理或用户认证。
